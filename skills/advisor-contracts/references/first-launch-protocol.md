# First Launch Protocol

Triggered when `team.start` detects the advisor briefing
(`agent-memory/advisors/briefings/<id>.md`) still holds the `AWAITING_FIRST_LAUNCH`
sentinel — the `briefing-awaiting.md` stub copied at hire time.

> Per spec 051: briefings are auto-generated by `python -m engine briefing build` and
> never hand-edited. First launch seeds the *source* artifacts (a decision + session
> record); the briefing then regenerates from them.

> **Empty-start is expected (G5).** On a freshly bootstrapped instance, `hot.md`
> has empty `Now` / `Recent decisions` / `Watch` sections (only the seeded
> "waiting for first append" placeholder). This is correct, not a fault — the
> cross-agent log fills as advisors close sessions and file decisions. First-launch
> advisors must not treat an empty `hot.md` as missing context or an init error.

## Steps

0. **Preflight (`engine doctor`)**: before bootstrapping, verify the DATA root, `hot.md`
   skeleton, and advisor canonicality. `--fix` seeds a missing `hot.md` skeleton so the
   first `engine file decision` this session can't crash on an absent section header (#49c):
   ```bash
   python -m engine doctor --advisor <id> --fix
   ```
1. **Introduce the advisor**: print identity block (role, language, philosophy, tone).
2. **Load prompts**: read Discovery Interview hints from advisor metadata (philosophy, domain anchors, tone).
3. **Seed the first decision**: file the creation seed (creation timestamp + hiring
   rationale) via `python -m engine file decision`. Focus and Toolbox are surfaced
   automatically by `python -m engine briefing build` from `SKILL.md` + `personality.md`
   — no manual briefing edit.
4. **Ask opening question**: one question tailored to the advisor's role to bootstrap conversation.
5. **Stamp `forge.hired-by`** in SKILL.md frontmatter (already done at creation; verify).
6. **Close via `python -m engine session close`** — the first session record clears the
   sentinel; the next `python -m engine briefing build` run produces the advisor's first
   real briefing.
7. Commit: `feat(team/<id>): first launch — bootstrap first session`.

## Constraints

- Never invented roles / facts. If a hint is absent, use placeholder `_(to be captured)_`.
- First launch is NOT a coding session; no code edits.
- Produces exactly one commit; no cascading work.
